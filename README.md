# URBANEON

> Modern streetwear for bold city living.

URBANEON is a premium urban fashion storefront focused on apparel, sneakers, accessories and everyday city essentials.

## Brand
- Company: URBANEON
- Location: Chicago, Illinois, United States
- Website: https://urbaneon-streetwear.com

## Features
- Responsive homepage and navigation
- Shop catalog with search, category filtering and sorting
- 16 catalog entries and 16 product pages
- Local product images and deterministic image assignments
- Cart with quantity controls and localStorage persistence
- Wishlist with localStorage persistence
- New Drops, Collections, Lookbook and Style Guides
- About, Support, Contact, FAQ, Shipping, Returns, Privacy, Terms and Accessibility
- Favicon, manifest, robots.txt and sitemap.xml
- No remote image dependencies

## Technologies
HTML5 · CSS3 · Vanilla JavaScript · JSON · SVG · GitHub Pages compatible
